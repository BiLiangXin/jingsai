# E题：复杂场景下多模态情感预测的数学建模与算法设计

本仓库收录2026年中国研究生数学建模竞赛E题的题目材料、标签、视频样本和专项特征文件，以及便于GitHub与ChatGPT阅读的文本说明。当前阶段为材料整理，尚无模型实现、训练结果或完成的参赛论文。

## 阅读入口

1. [赛题全文（Markdown）](docs/problem.md)：由原始Word转换，保留完整正文、表格、两幅原图和参考文献；代码截图另附可复制转录。
2. [数据说明与字段字典](docs/data-guide.md)：附件用途、标签表实测统计、PKL接口说明、数据划分与使用约束。
3. [附件1全部100条标签与英文文本](docs/samples/labels-100.csv)。
4. [附件2前10条记录示例](docs/samples/labels-feature-first10.csv)。

## 三个建模任务

| 问题 | 输入 | 主要工作 |
|---|---|---|
| 1 | 附件1的100条原始视频及文本 | 提取三模态特征、建立时序对齐并记录可复现流程 |
| 2 | 附件2训练/验证数据，附件3专项样本 | 局部模态缺失条件下的极性与强度预测 |
| 3 | 附件2训练/验证数据，附件4专项样本 | 情感预测、模态贡献分析与关键证据定位 |

## 数据可用范围

`E题数据/附件2-数据集特征文件/` 下的 `aligned_50.pkl`（993842861字节）和 `unaligned_50.pkl`（2897003035字节）因体积过大未纳入Git，本地原件保留。完整训练时需从原始数据包将它们放回该目录。字段形状来自赛题说明，实际PKL内容尚未核验。

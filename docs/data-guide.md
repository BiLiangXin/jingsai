## 2. 标签表：实际读取结果

两份工作簿均以 `label` 工作表为数据源，首行为列名。

| 文件 | 数据行数 | 列数 | 正向 | 中性 | 负向 |
|---|---:|---:|---:|---:|---:|
| `label-100.xlsx` | 100 | 5 | 57 | 25 | 18 |
| `label.xlsx` | 4850 | 6 | 2370 | 1100 | 1380 |

`label.xlsx` 的 `mode` 列：`train` 3395条、`valid` 728条、`test` 727条。以上是标签表记录计数，尚未与完整PKL逐项比对。

| 列名 | 含义 | 读取建议 |
|---|---|---|
| `video_id` | 原始视频标识；附件1对应目录名 | 按字符串保留开头的减号及大小写 |
| `clip_id` | 视频片段标识；附件1对应MP4文件名主体 | 按字符串处理，与video_id共同构成样本键 |
| `text` | 英文转写文本 | 这是原始文本，不是PKL中的数值文本特征 |
| `label` | 连续情感强度 | 实际表格中为字符串形式的数值，分析前显式转换为浮点数 |
| `annotation` | `Negative`、`Neutral`或`Positive` | 核查与情感强度符号是否一致 |
| `mode` | `train`、`valid`或`test` | 仅附件2标签表实际具有此列 |

题目定义：`[-3,0)`为负向，`0`为中性，`(0,3]`为正向。三分类整数编码需从实际文件核对，不能自行猜定。

附件1还有一个“修改说明”工作表，记载“列数6”和训练/验证/测试数量，但实际 `label` 表仅有5列、没有 `mode`。使用时以实际数据表为准；若需要划分信息，应按 `(video_id, clip_id)` 与附件2标签表匹配并检查匹配结果。

## 3. 完整特征文件：题目规定的接口

两个文件均为Python Pickle字典，顶层键为 `train`、`valid`、`test`。每个划分内部按字段存储，同一索引位置对应同一个样本：

```python
split = data['train']
sample_id = split['id'][j]
text_features = split['text'][j]
audio_features = split['audio'][j]
vision_features = split['vision'][j]
target = split['regression_labels'][j]
```

| 字段 | 题目中的定义 |
|---|---|
| `id` | `video_id_clip_id`格式的样本标识；拆分时注意video_id本身可能含下划线 |
| `raw_text` | 原始英文转写文本 |
| `text` | 预计算的BERT类连续文本表示，每样本50×768 |
| `text_bert` | 3×50整数输入：词元编号、注意力掩码、分段编号；需经BERT编码，与text二选一 |
| `audio` | 语音时序特征，特征维度74；题目未规定每维物理含义 |
| `vision` | 视觉时序特征，特征维度35 |
| `audio_lengths`、`vision_lengths` | 未对齐版本的语音和视觉有效长度 |
| `annotations` | 文字情感极性 |
| `classification_labels` | 分类标签，具体数值映射待核验 |
| `regression_labels` | 连续情感强度 |

| 文件 | text | audio | vision |
|---|---|---|---|
| `aligned_50.pkl` | `(N,50,768)` | `(N,50,74)` | `(N,50,35)` |
| `unaligned_50.pkl` | `(N,50,768)` | `(N,500,74)` | `(N,500,35)` |

`N`为当前划分样本数。对齐版本的50个位置跨模态对应；未对齐版本的音视频保留独立时序。最大长度、有效长度和填充区间需要分别处理。题目没有给出完整的逐词时间戳或秒级映射，不能直接把序列索引视为时间。

## 4. 专项测试与建模约束

- 附件3的缺失是一个或多个模态中的连续局部区间全零，不等同于整模态缺失。实现时需要区分缺失区间与填充区间，规则需经数据核验。
- 附件4三模态完整，需输出极性、强度、主要参考模态、模态作用程度和关键证据定位，并能回看原始素材。
- 训练、验证、专项推理保持相同特征版本及输入接口。
- 模型参数在附件2训练集学习；结构、超参数与决策阈值在验证集选择。附件3、4仅用于最终专项推理。
- 极性评价用Accuracy、F1；强度评价用MAE、Pearson相关系数。F1平均方式等未明确细节应在实现中说明。
- 题目要求以所提供数据为唯一数据来源；可使用开源工具和预训练模型，并记录版本及参数。
- 问题1需覆盖100条原始样本；竞赛最终附件上限50MB。GitHub材料仓库与最终参赛提交包需要分别整理。

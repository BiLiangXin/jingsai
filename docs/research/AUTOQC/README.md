# S06 带拒判机制的跨模态证据自动核验

本任务按 S06-AUTOQC-01 执行，不训练情感模型。固定 M2 seed17 epoch2、TRAIN scaler、V1、E1 和附件3/4原预测不变。通用 faster-whisper small.en 仅对原音轨做无提示自由转写；给定官方词序的 PocketSphinx 对齐是另一条条件化路径。二者一致只构成机器证据，不是人工真值或官方AV特征生产时间。

协议先于首个ASR结果固定在 [PROTOCOL.json](PROTOCOL.json)：模型revision和权重/词表哈希、CPU int8、转写参数、词规范化、`D_edit<=0.35`、目标普通词唯一精确覆盖、最大边界差`<=0.25s`和最近真实PTS帧差`<=0.10s`。不按A4或R1记录调节。词级Levenshtein的唯一匹配要求该配对出现在**所有**最优路径；重复词等成本歧义拒判。`D_edit`是两份转写的不一致率，不是经真值校准的WER。`D_t=max(|start_A-start_B|,|end_A-end_B|)`仅在唯一同词且两边时间有效时计算。

Q1 100条均完成来源、哈希、支持区间与真实帧解码核验。原强制对齐66条程序通过、34条异常；新增严格机械QC0为59、加自由ASR词一致QC1为31、再加双路径时间/PTS与拒判QC2为1。词级声学状态按样本为DUAL 3、SINGLE 2、CONFLICT 63、TEXT_ONLY 32；QC2是累积且更严格的最终支持，不能把DUAL 3等同于QC2通过3条。真实自然对齐准确率未知。聚合数据在 `reports/s06_autoqc/Q1_AGGREGATE.json`，逐条转写和结果只留本地私有。

固定最多12条音频诊断：12个未改动副本中QC2拒判12条，说明门槛过严且不能把突变拒判当作优秀准确性。原始通过的对照中，0.5秒侧车错移QC0新增拒判2/6、QC1新增拒判1/3；1.0秒QC0为6/6、QC1为3/3。前缀1秒静音实际ASR回放12条，其中11条有唯一可比词，最大时间平移等变误差1秒；固定时长范围音轨错配12/12仅由**来源哈希**发现，不代表ASR能辨别自然错配。按词序变动及否定词变动保留全部可资格结果，分母和不适用情况见聚合JSON。Q1原时间不是逐词真值，以上只说明受控扰动行为。

附件4的固定算法先比较冻结CSV字节哈希及原类别、强度、贡献、主要模态和关键窗口，再检查源hash/时间单位/实际PTS。普通词未唯一匹配、时间不合法、两估计冲突或无靠近帧时，拒绝高精度时间解释；保留预测和文本位置。特殊词、标点、padding不造秒数，未知未映射词元会降级。`official_av_feature_production_timing=UNKNOWN`恒定。原20条审核自述18接受/2未解决只作历史，绝不作为本算法阈值或真值。

独立只读技术复核在Q1 V6与A4执行前对最终源码、合成测试和聚合给出PASS；这不认证音轨内容。ASR隔离环境6项合成测试退出码0，作者首次漏取CT2 vocabulary导致模型加载失败，在首个ASR结果前补齐同一固定revision并保留失败事实。初始Q1审核脚本曾误读早期未对齐副本，V1/V2结果保留；最终读取后续 `q1_alignment` 的V6。没有基于A4结果重选模型、阈值或样本。

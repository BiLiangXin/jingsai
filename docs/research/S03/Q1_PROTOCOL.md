# Q1 extraction protocol — specified before extraction

Independent interface, never an imitation of unknown official 768/74/35 features and never supplied to M2. All100 official Excel rows retained unchanged privately, including original labels. Identity is used only to map those Q1 rows to their own source clips, never to retrieve external sentiment labels. No supervised learning.

User explicitly authorized separate installation of general tools/weights. Frozen installed versions, executable and all bundled acoustic/dictionary hashes: reports/s03_readiness/Q1_TOOLS.json. PocketSphinx5.1.1 English acoustic/dictionary model is a general speech aligner, not a sentiment predictor. imageio-ffmpeg0.6.0 supplies local FFmpeg. PocketSphinx and wrapper BSD licenses; bundled FFmpeg reports its own build/license, retained privately. Sources checked 2026-09-25: https://pocketsphinx.readthedocs.io/en/latest/pocketsphinx.html ; https://github.com/cmusphinx/pocketsphinx/blob/main/LICENSE ; https://github.com/imageio/imageio-ffmpeg . No emotion datasets/weights downloaded.

Text: preserve original Excel text; tokenize lowercase ASCII alphabetic words with optional internal apostrophe, plus digit runs. Explicitly record normalization and omitted punctuation; non-ASCII letters or dictionary-OOV tokens block forced alignment, never silently delete words. SHA256 token hashing into128 signed count dimensions (single lexical token, collision possible), no trained language representation. This is a reproducible lexical descriptor, not contextual semantics.

Audio: actual first audio stream, mono16kHz PCM16. FFmpeg copyts and ashowinfo preserve actual presentation start; detect discontinuities. Frames25ms (400samples), hop10ms (160), Hann window, 512FFT, 26triangular mel filters 0..8kHz, log energies then orthonormal DCT first13 coefficients; add log RMS, zero-crossing rate and spectral centroid =>16dimensions. No sample statistics learned. Silence remains a measured signal, not automatically missing.

Vision: actual decoded first video stream with presentation timestamps; select first frame and subsequent frames at least0.2s after prior selected frame (no synthetic CFR times), resize64x64 RGB. Six RGB mean/std, eight-bin histogram per HSV channel (24), nine-bin magnitude-weighted gradient orientation histogram =>39dimensions. No face detection is claimed; backgrounds and nonfaces retained. Actual PTS recorded, VFR never inferred as index/fps.

Forced alignment: official normalized tokens plus actual16k waveform into PocketSphinx set_align_text; returned acoustic segment start/end in100Hz frames. Check token order/completeness, positive durations, bounds, monotonicity and actual stream continuity. Non-English/OOV/failed paths UNALIGNED, words have null timestamps; clip-level actual signal time retained. Mechanically validated computed alignments are not human-annotated ground truth; manual timing accuracy remains UNKNOWN. At least one successful case gets an auditable private HTML with audio, actual frame, waveform and word timestamps; never infer official Q3 correspondence.

All100 have text/audio/vision arrays when extraction succeeds; failures explicit, never replaced with all-zero success. Per-token rows link acoustic feature frame intersections and nearest actual video PTS. Unaligned rows retain segment summaries and null word links. Full original descriptors plus variable-length sequences and trace stored privately in compressed NPZ/JSON/CSV. Public evidence contains only counts, dimensions, quality summaries and hashes.

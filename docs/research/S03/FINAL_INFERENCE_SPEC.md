Other fields ignored without indexing; raw_text never accessed.

Optional sample identifier: at most one of id/ids, length N (a scalar is allowed for N=1); scalar strings/numbers or flat scalar tuples/lists serialize deterministically. No external matching. Without identifiers, use stable zero-based row ordinal. Duplicated identifiers within a file fail, no row deletion. Empty populations, malformed shape/support, nonfinite values and ambiguous identifiers fail explicitly.
